# pom-partner-hub-mvp

Frontend-Mockup für das **Place of Motion Partner-Dashboard** (React + Tailwind, nur Frontend mit Dummy-Daten).

## Schnellstart
1. Abhängigkeiten installieren:
   ```bash
   npm install
   ```
2. Entwicklungsserver starten:
   ```bash
   npm run dev
   ```
3. Im Browser öffnen:
   - `http://localhost:4173`

## Weitere Befehle
```bash
npm run build
npm run lint
```

## Hinweis
- Keine echte Authentifizierung
- Keine Datenbank
- Keine Backend-Anbindung
